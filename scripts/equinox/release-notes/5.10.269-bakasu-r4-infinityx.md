# Equinox Infinity X BakaSU Edition 5.10.269 r4

Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
BakaSU edition by **Nanairo8890** with LF52406's permission, packaged for **Project Infinity-X 4.1**
(build of 17 October 2026, Android 17).

## Files

- `Equinox-5.10.269-BakaSU-mondrian-InfinityX-20261017.zip`: AnyKernel3 zip. Flash it from a recovery or a
  kernel flasher; it only replaces the kernel `Image` and keeps the ROM's ramdisk, header and bootconfig.
- `BakaSU_v4.2.0-rc3_35231-arm64-v8a-release.apk`: BakaSU manager 35231, from BakaSU's official CI. Install it
  over the previous manager.
- `CHANGELOG.es.txt`, `CHANGELOG.en.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog.

## Before flashing

- Back up your `boot` partition first.
- After flashing, `adb shell su -c "dmesg | grep -i 'disagrees about version'"` should print nothing.
- If you update Infinity-X, flash the zip again afterwards, because the ROM ships its own kernel.
- For MistOS, use the BakaSU edition at [nanairo8890/Equinox-Kernel-sm8450](https://github.com/nanairo8890/Equinox-Kernel-sm8450).

- Los CRC de este kernel coinciden con los 337 módulos de `vendor_boot` y los 390 de
  `vendor_dlkm` de Infinity-X 4.1, y también con los de MistOS 5.1 Beta 20261011.

**BakaSU actualizado (versión 35233)**
- BakaSU `f308ed09` (v4.2.0-rc3 + 62 commits, versión 35233): la versión más nueva del PR
  [#624](https://github.com/Baka-SU/BakaSU/pull/624) "kernel: sync for latest susfs", que el
  autor actualizó el 17 de octubre ("sync again" y "fix"). Sus cambios en `selinux_hide.c`
  solo afectan a kernels 6.6 o más nuevos: en este kernel 5.10 el código de BakaSU es el
  mismo que en r3 y solo cambia el número de versión.
- El `main` de BakaSU sigue bloqueando la compilación con SUSFS, así que este PR es lo más
  reciente que se puede usar con SUSFS. De `main` solo quedan fuera `d7260ca1`
  (context_add_hash), que no aplica a Linux 5.10, una actualización de dependencias de `ksud`
  (libc) y un cambio en la configuración de Renovate, que no son parte del kernel.
- **Manager: BakaSU 35231** (`BakaSU_v4.2.0-rc3_35231-arm64-v8a-release.apk`), del CI oficial
  de BakaSU (`main` en `2489b385`), firmado con la misma clave que el 35217 y el 35229. La
  interfaz con el kernel sigue en la versión 5: se instala encima del manager anterior, sin
  desinstalarlo.

**SUSFS actualizado (`ca7093a1`)**
- SUSFS v2.3.0 en `ca7093a1` (antes `82f08351`). Trae el arreglo "Fix another selinux leak in
  `sel_open_handle_status()`": antes, una vez creado el estado falso de SELinux, abrir el
  archivo de estado podía devolverles a las apps el estado real; ahora las apps siempre
  reciben el falso cuando existe.

**Sin cambios**
- NoMount sigue en v2.1.1 de maxsteeel, la versión más reciente.

**Comprobaciones**
- KMI contra Equinox limpio: 0 CRC cambiados y 0 símbolos eliminados (solo se agrega
  `put_pid_ns`, igual que en r1, r2 y r3).
- Todavía no se probó en el teléfono.

### English

**Compatibility**
- Separate package for Project Infinity-X 4.1 (17 October 2026 build, Android 17, October 2026 security patch). Its stock kernel is `5.10.269-gki-g283772ceb844`, compiled with Clang r596125 and with the same kernel config as MistOS 5.1 Beta's (only compiler-detection options differ). Its vendor modules are rebuilt.
- Vendor module CRCs match the 337 `vendor_boot` and 390 `vendor_dlkm` modules of Infinity-X 4.1, and also those of MistOS 5.1 Beta 20261011.
- Installation is unchanged: the AnyKernel3 zip only replaces the `Image` and keeps the ROM's ramdisk, header and bootconfig. If you update Infinity-X, flash the zip again, because the ROM ships its own kernel.

**Changes**
- BakaSU updated to version 35233 (commit `f308ed09`, v4.2.0-rc3 + 62 commits), the newest version of PR #624 "kernel: sync for latest susfs", which BakaSU's author updated on 17 October ("sync again" and "fix"). Its `selinux_hide.c` changes only affect kernels 6.6 and newer: on this 5.10 kernel BakaSU's code is the same as in r3, and only the version number changes.
- BakaSU's `main` still blocks SUSFS builds, so this PR is the newest BakaSU that can be used with SUSFS. The only things from `main` not included are `d7260ca1` (context_add_hash), which does not apply to Linux 5.10, a `ksud` dependency update (libc) and a Renovate config change, which are not part of the kernel.
- BakaSU manager 35231 (`BakaSU_v4.2.0-rc3_35231-arm64-v8a-release.apk`), from BakaSU's CI (`main` at `2489b385`), signed with the same key as 35217 and 35229. The kernel interface is still version 5: install it over the previous manager, without uninstalling.
- SUSFS updated to `ca7093a1` (v2.3.0, previously `82f08351`), with the fix "Fix another selinux leak in `sel_open_handle_status()`": before, once the fake SELinux status existed, opening the status file could return the real one to apps; now apps always get the fake one when it exists.

**Unchanged**
- NoMount stays at v2.1.1 by maxsteeel, the latest version.

**Checks**
- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` is added, as in r1, r2 and r3).
- Not tested on a phone yet.

### Русский

**Совместимость**
- Отдельный пакет для Project Infinity-X 4.1 (сборка от 17 октября 2026 г., Android 17, патч безопасности за октябрь 2026 г.). Её штатное ядро — `5.10.269-gki-g283772ceb844`, собранное Clang r596125 с той же конфигурацией ядра, что и у MistOS 5.1 Beta (отличаются только опции, которые определяют возможности компилятора). Модули вендора в ней пересобраны.
- Контрольные суммы CRC модулей вендора совпадают с 337 модулями `vendor_boot` и 390 модулями `vendor_dlkm` Infinity-X 4.1, а также с модулями MistOS 5.1 Beta 20261011.
- Установка не изменилась: zip AnyKernel3 заменяет только `Image` и сохраняет ramdisk, заголовок и bootconfig прошивки. После обновления Infinity-X прошейте zip заново, так как прошивка содержит собственное ядро.

**Изменения**
- BakaSU обновлён до версии 35233 (коммит `f308ed09`, v4.2.0-rc3 + 62 коммита) — это самая новая версия PR #624 «kernel: sync for latest susfs», который автор BakaSU обновил 17 октября («sync again» и «fix»). Его изменения в `selinux_hide.c` касаются только ядер 6.6 и новее: в этом ядре 5.10 код BakaSU такой же, как в r3, меняется только номер версии.
- Ветка `main` у BakaSU по-прежнему блокирует сборку с SUSFS, поэтому этот PR — самая новая версия BakaSU, которую можно использовать с SUSFS. Из `main` не вошли только коммит `d7260ca1` (context_add_hash), который неприменим к Linux 5.10, обновление зависимости `ksud` (libc) и изменение настроек Renovate, которые не относятся к ядру.
- Менеджер BakaSU 35231 (`BakaSU_v4.2.0-rc3_35231-arm64-v8a-release.apk`) из CI BakaSU (`main` на `2489b385`), подписан тем же ключом, что и версии 35217 и 35229. Интерфейс с ядром по-прежнему версии 5: устанавливайте поверх предыдущего менеджера, не удаляя его.
- SUSFS обновлён до `ca7093a1` (v2.3.0, ранее `82f08351`) с исправлением «Fix another selinux leak in `sel_open_handle_status()`»: раньше, когда поддельный статус SELinux уже существовал, при открытии файла статуса приложения могли получить настоящий статус; теперь приложения всегда получают поддельный, если он существует.

**Без изменений**
- NoMount остаётся на версии v2.1.1 от maxsteeel — это самая новая версия.

**Проверки**
- KMI относительно чистого Equinox: 0 изменённых CRC и 0 удалённых символов (добавлен только `put_pid_ns`, как в r1, r2 и r3).
- На телефоне ещё не проверялось.
